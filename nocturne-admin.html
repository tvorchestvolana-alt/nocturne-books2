Файлы книги

Выбери книгу и загрузи файл с любым названием — в том числе русским. Панель сама создаст безопасное имя на основе slug книги и сохранит путь в её карточке. Для файлов используется приватный bucket book-files.

При выборе EPUB страницы и главы рассчитываются автоматически. При необходимости их можно исправить вручную.

Отвязка убирает файл из карточки, но не удаляет его из Storage. Новая загрузка заменяет файл с тем же именем.

Галерея иллюстраций

Выбери книгу, затем добавь несколько изображений. Названия файлов могут быть на русском. Стрелки меняют порядок, кнопка «Удалить» удаляет изображение из галереи и хранилища.

Серии

Книги вне серий оставляй с пустым полем «Серия».
